# FitnessTracker

FitnessTracker is a native Windows desktop application built with C# and .NET. It provides users with an offline, desktop-optimized interface to log daily workouts, track exercise routines, manage personal fitness goals, and monitor overall health progress.

---

## Features

### For Users
- **Workout Logging:** Easily record exercises, sets, reps, and weights lifted.
- **Goal Management:** Set daily or weekly targets for fitness and track your status.
- **Progress Tracking:** Review historical workout logs and evaluate personal performance over time.
- **Desktop Friendly:** Optimized layout and shortcuts for Windows PC users.

---

## Tech Stack

- **Language:** C#
- **Framework:** .NET Framework / .NET Core
- **UI Framework:** WPF (Windows Presentation Foundation) / WinForms
- **Database:** SQL Server

---

## Prerequisites

- **Operating System:** Windows 10 / Windows 11
- **IDE:** Visual Studio 2022 (or newer) with **.NET desktop development** workload installed
- **Runtime:** .NET Runtime corresponding to the project target

---

## Installation & Setup

Follow these steps to set up and run the application locally.

### 1. Repository Setup
Clone the repository to your local machine:

git clone https://github.com/kyawzinwindev/FitnessTracker.git
cd FitnessTracker

### 2. Open Project in Visual Studio
1. Launch **Visual Studio**.
2. Select **Open a project or solution**.
3. Navigate to the cloned `FitnessTracker` directory and open the `.sln` file.

### 3. Restore Packages & Build
1. In Visual Studio, right-click the solution in **Solution Explorer** and select **Restore NuGet Packages**.
2. Build the solution by pressing `Ctrl + Shift + B` or selecting **Build > Build Solution**.

### 4. Run the Application
Press `F5` or click the **Start** button in Visual Studio to launch the application.
